# SchemeMatch

## Project Introduction

SchemeMatch is a Python-based academic project that aims to intelligently match applicants with relevant government schemes based on their profile attributes. By leveraging machine learning techniques, the system analyzes applicant characteristics — such as age, income, sector, business stage, and location — and recommends the most suitable schemes from a curated dataset.

## Project Objective

- Build a structured dataset of government schemes and applicant profiles.
- Develop a matching algorithm using clustering and similarity-based techniques to recommend relevant schemes to applicants.
- Provide an interactive web interface (via Streamlit) for users to input their details and receive scheme recommendations.
- Visualize insights from the data to support analysis and decision-making.
